## Frequently asked questions

{% endheader %}

{% column %}

{: .question}
{% header %}

### How does screen reader support make PDF documents more accessible?

{% endheader %}

{: .answer}
{% header %}

Screen reader support lets visually impaired users navigate and consume PDF content through assistive technologies. Tagged PDFs are read in a structured order, helping applications improve accessibility and meet compliance requirements.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Why is keyboard navigation important for PDF accessibility?

{% endheader %}

{: .answer}
{% header %}

Keyboard navigation lets users move through pages, outlines, and toolbar actions using shortcuts and tab keys. This helps users with motor impairments and anyone who prefers keyboard-driven workflows stay productive without a mouse.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### How do high contrast themes improve the PDF reading experience?

{% endheader %}

{: .answer}
{% header %}

High contrast themes improve color differentiation between text, icons, and page backgrounds. They make PDF content easier to read for users with low vision and across different lighting conditions.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Which languages benefit from a right-to-left layout in the PDF Viewer?

{% endheader %}

{: .answer}
{% header %}

Right-to-left layouts support languages such as Arabic and Hebrew by mirroring the toolbar, panels, and navigation. This provides a natural and intuitive reading experience for RTL language users.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Can accessibility features be combined in a single PDF Viewer experience?

{% endheader %}

{: .answer}
{% header %}

Yes. Screen reader support, keyboard navigation, high contrast themes, and right-to-left layouts can be used together to build inclusive PDF reading experiences that adapt to different user needs.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### How do accessibility features improve enterprise document workflows?

{% endheader %}

{: .answer}
{% header %}

Teams that share reports, contracts, and training material across regions can rely on screen reader support, keyboard navigation, high contrast themes, and right-to-left layouts to make documents usable for every employee and stakeholder. This helps enterprises deliver consistent and inclusive document experiences across global teams.

{% endheader %}

{% endcolumn %}
