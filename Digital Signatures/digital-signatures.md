## Frequently asked questions

{% endheader %}

{% column %}

{: .question}
{% header %}

### Does the PDF Viewer SDK support certificate-based digital signatures?

{% endheader %}

{: .answer}
{% header %}

Yes. The Syncfusion PDF Viewer SDK supports digital signature workflows, and advanced certificate-based signing is enabled through integration with the Syncfusion PDF Library.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Can signed PDF documents be validated?

{% endheader %}

{: .answer}
{% header %}

Yes. Digital signature validation can verify whether a document has been modified after signing by checking signature validity, trust status, and document integrity through Syncfusion PDF Library support.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Can the visual appearance of a digital signature be customized?

{% endheader %}

{: .answer}
{% header %}

Yes. Visible digital signature appearance can be customized with signer information, images, timestamps, and related presentation details through the Syncfusion PDF Library.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Does this support complete signing workflows?

{% endheader %}

{: .answer}
{% header %}

Yes. The Syncfusion PDF Viewer SDK supports workflows that include signature field preparation, document signing, signature validation, and review for approval-driven PDF processes.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Are digital signatures the same as handwritten or typed signatures?

{% endheader %}

{: .answer}
{% header %}

No. Digital signatures are certificate-based and used to verify authenticity and integrity. Handwritten or typed signatures are visual signature experiences and serve different workflow needs.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Is Syncfusion PDF Library required for advanced digital signature operations?

{% endheader %}

{: .answer}
{% header %}

Yes. Advanced PKI-based digital signing, validation, and visible signature appearance customization require integration with the Syncfusion PDF Library.

{% endheader %}
