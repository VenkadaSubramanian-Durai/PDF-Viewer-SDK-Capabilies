{% header %}

## Frequently asked questions

{% endheader %}

{% column %}

{: .question}
{% header %}

### Does PDF redaction permanently remove content?

{% endheader %}

{: .answer}
{% header %}

Yes. Once redactions are applied, the underlying content is permanently removed from the document and is not retained beneath the visible mark.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Can I redact repeated words across a PDF?

{% endheader %}

{: .answer}
{% header %}

Yes. You can search for matching text and mark multiple occurrences for redaction, which helps when the same confidential term appears throughout a document.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Can I redact full pages in a PDF document?

{% endheader %}

{: .answer}
{% header %}

Yes. Entire pages and selected page ranges can be marked for redaction when sensitive information spans larger sections of the file.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Is redaction available for automated workflows?

{% endheader %}

{: .answer}
{% header %}

Yes. Redaction workflows can be automated with APIs and custom business logic to help process larger document sets more efficiently.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Can I mark content for redaction during document review?

{% endheader %}

{% endheader %}

{: .answer}
{% header %}

Yes. Sensitive content can be marked directly during review by using the toolbar or context menu inside the viewer.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Why use PDF redaction instead of visual masking?

{% endheader %}

{: .answer}
{% header %}

Visual masking only hides content on the page, while redaction is intended to remove the underlying information from the final saved PDF.

{% endheader %}

{% endcolumn %}
