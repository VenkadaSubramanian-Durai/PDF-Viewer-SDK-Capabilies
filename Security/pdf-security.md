{% header %}

## Frequently asked questions

{% endheader %}

{% column %}

{: .question}
{% header %}

### Can the PDF Viewer open password-protected PDF files?

{% endheader %}

{: .answer}
{% header %}

Yes. The PDF Viewer can open password-protected PDF documents by requesting the required password during document loading.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Does the PDF Viewer support PDF redaction?

{% endheader %}

{: .answer}
{% header %}

Yes. Redaction is supported for removing or obscuring sensitive information in PDF documents on supported platforms.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Are digital signatures the same as electronic signatures?

{% endheader %}

{: .answer}
{% header %}

No. Digital signatures are certificate-based and help verify document authenticity and integrity. They are different from standard electronic signature input.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Can I validate digital signatures in signed PDF files?

{% endheader %}

{: .answer}
{% header %}

Yes. Signature validation is supported for checking certificate authenticity and identifying whether a document was modified after signing.

{% endheader %}

{% endcolumn %}

{% column %}

{: .question}
{% header %}

### Does digital signature support require additional integration?

{% endheader %}

{: .answer}
{% header %}

Yes. The documented digital signature workflows in this source set require Syncfusion PDF Library integration.

{% endheader %}

{% endcolumn %}
